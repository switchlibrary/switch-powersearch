# SWITCH Library Power Search Plugin

This plugin for Google Chrome was adapted from the [Leiden University Libraries Library Search Plugin](https://github.com/LeidenUniversityLibrary/Library-Search-Plugin-Public).

It allows users to search a number of library catalogs, Google Scholar, WorldCat, etc. at once, opening a new browser tab with search results for each selected site.

The plugin is available in the [Chrome Web Store](https://chromewebstore.google.com/detail/switch-consortium-library/jibghnpiodecibgclmholabkfkhcgdid).
